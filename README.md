# ParentalControl

## Состав
- `watcher.py` — логика мониторинга: убивает процессы из `config.json`, поднимает локальную страницу-заглушку, правит `hosts`.
- `blocked.html` — страница, которую видит ребёнок вместо приложения.
- `service.py` — оборачивает `watcher.py` в Windows-службу (pywin32).
- `config.json` — список блокируемых процессов, домен и порт локальной страницы.
- `install.ps1` — ставит всё одной командой и настраивает права доступа.

## Вариант А: один exe одним кликом (рекомендуется)

Нужно собрать один раз на Windows-машине с установленным Python:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Появится `dist\Install.exe`. Дальше раздаёшь только этот файл — двойной
клик сам покажет окно UAC (благодаря `admin_manifest.xml`) и поставит всё
автоматически, Python на целевой машине для этого не нужен (служба тоже
скомпилирована в exe).

## Вариант Б: без компиляции, через install.ps1
1. Отредактируй `config.json` под себя (список `.exe`, домен, порт).
2. Запусти PowerShell **от имени администратора**.
3. Выполни:
   ```powershell
   powershell -ExecutionPolicy Bypass -File install.ps1
   ```
   (этот вариант требует установленного Python на целевой машине)

## Разблокировка паролем
На странице блокировки есть поле для пароля родителя (хэш в `config.json`,
`unlock_password_hash`, генерируется через `make_password_hash.py`).

- `unlock_duration_minutes` > 0 — защита снимается на это время и включается
  сама обратно.
- `unlock_duration_minutes` = 0 — защита отключается **навсегда**: служба,
  запланированная задача и вся папка установки удаляются из системы. Это
  необратимо — для повторной установки нужно заново запускать `Install.exe`.

## Обязательное условие
Учётная запись ребёнка должна быть **стандартной**, не администраторской:
`Параметры → Учётные записи → Семья и другие пользователи → Изменить тип учётной записи → Стандартный пользователь`.

Без этого шага ограничения на службу и файлы можно обойти через "Запуск от имени администратора".

## Как это работает
- Защита строится на правах доступа (`sc sdset`, `icacls`), а не на сокрытии: служба видна в `services.msc` под своим именем.
- Обычный пользователь не может остановить/удалить службу или файлы — у него просто нет на это прав.
- Администратор (родитель) в любой момент может зайти под своей учёткой и всё изменить или удалить.

## Управление (от администратора)
```powershell
cd "C:\Program Files\ParentalControl"
python service.py stop
python service.py remove
```
